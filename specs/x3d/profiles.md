# X3D profiles: the components and levels each includes

The tables `vrml.x3d.profiles` holds, recorded as data. Each is the
"Components and levels" table of the profile's annex in ISO/IEC 19775-1:2023
(X3D 4.0), read at
`https://www.web3d.org/documents/specifications/19775-1/V4.0/Part01/`;
the X3D 4.1 committee draft gives the same tables. One set of tables serves
every version: the X3D 3.x specifications' own annexes are not transcribed.
